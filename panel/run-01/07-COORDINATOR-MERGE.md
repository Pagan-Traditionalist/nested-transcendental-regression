## Adopted main-line nest (owner keep/cut)

### Entry (not a nest step)

If the sword is shiny → reflective; the sword is shiny; therefore reflective.  
Do not fight validity. Change level of explanation.

### Step 1 — Secured

**Q:** What must already be the case for P2 — “the sword is shiny” — to be an **objective representation of empirical reality** at all?

**A (minimal):** Subject ↔ Object under **Space**, **Time**, and **Causality** (affection referred to an empirical object as its cause — object vs unordered sensation).

**Grade:** constitutive of *objective empirical purport*, not mind-independent realism.

**Follow-up if proposition-first:** Not justification. What must already be the case for there to be an empirical sword represented as shiny.

### Step 2 — Secured (refined wording from Critic + Constructor)

**Q:** **Given that** objective empirical representation requires a subject–object structure in a presenting act, **what must be true of the *role* occupied by the subject-pole in *that same act*** — such that the object appears *to* it — **without** treating that pole, *in that act and respect*, as one more object among the act’s objects?

**A (minimal):** Whatever occupies the subject-role in a given act is not, **in that same act and respect**, the object of that act. Reflection **relocates** the boundary; it does not eliminate the need for a subject-pole. **No numerical dualism.**

**MAIN-LINE STOP HERE** for the ideal sword diagnostic.

### Step 3 — Branch / Provisional (not default)

**Gate:** interlocutor identifies subject-pole with ordinary empirical me.

**Q:** **Given that** the subject-role in an act is not the object of that same act, **what must be true for the empirical “me” itself to appear as an object of experience?**

**A (weakened):** Empirical ego *as appearing content* does not exhaust the subject-pole of the act in which that content appears. Hold role/exhaustion grade only — **not** Pure Subject / soul.

### Step 4 — Off line / Speculative
